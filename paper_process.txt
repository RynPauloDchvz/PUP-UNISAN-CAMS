================================================================================
PUP UNISAN CAMS - EVENT APPROVAL & PAPER PROCESS WORKFLOW (OFFICIAL 5-STEP)
File: paper_process.txt
================================================================================

[OVERVIEW]
Ang bagong opisyal na 5-Hakbang (5-Step) na proseso para sa pag-apruba ng event proposal,
manual paper routing, at pag-upload ng mga opisyal na dokumento sa PUP Unisan CAMS.
Inalis na ang lumang redundant na Initial Review ng Admin sa system, ngunit nananatili
ang pagsusuri ng Adviser sa mga in-upload na requirements bago ito dumeretso sa Final Admin Review.

================================================================================
BUONG PROSESO (PHASES & 5-STEP SYSTEM WORKFLOW)
================================================================================

PHASE 1: SYSTEM (INITIAL PROPOSAL REVIEW)
--------------------------------------------------------------------------------
1. Step 1: Pending Adviser (Initial Review)
   - Gumagawa ang Student Org ng Event Proposal / Request Letter sa loob ng system.
   - Status: "Pending Adviser"
   - Lokasyon: Office of the Org Adviser (Initial Review)
   - Adviser Action (sa dashboard.html):
     * APPROVE: Diretsong magiging "Adviser Approved" (Ready for Printing & F2F Routing).
     * REJECT: Magiging "Rejected" kalakip ang opisyal na Rejection Remarks/Reason.
       Makikita ito ng Organizer sa Document Tracking modal.

PHASE 2: MANUAL / F2F (FORM & ROUTING SIGNATURES)
--------------------------------------------------------------------------------
2. Step 2: Adviser Approved (Printed & F2F Routing / Gathering Signatures)
   - Kapag na-approve ni Adviser, puwede nang i-print ng Org ang Request Letter.
   - Dadalhin ng Student Org ang printed letter sa Office of Student Affairs and Services (OSAS / Admin).
   - Iaabot ng Admin sa Student Org ang opisyal na hard copy form (PUP-RPCA-5-OFSS-003).
   - Iikutin ng Student Org ang form at letter para papirmahan nang pisikal sa mga sumusunod:
     1. Organization Adviser (Manual Signature)
     2. Area Chairperson
     3. Security Office
     4. Property Office
     5. Head of Student Affairs (Recommending Approval)
     6. Campus Director (Dr. Edwin G. Malabuyoc)

PHASE 3: REQUIREMENTS VERIFICATION (ADVISER CHECK)
--------------------------------------------------------------------------------
3. Step 3: Adviser Finalize Event Requirements (DB Status: Permit Verification)
   - Kapag kumpleto na ang lahat ng manual na pirma sa Form 003 at Request Letter,
     i-i-scan o pipicturan ito ng Student Org at i-u-upload sa Document Vault.
   - Pagka-upload, magiging status: "Permit Verification".
   - Lokasyon: Office of the Org Adviser (Requirements Verification).
   - Bubuksan ni Adviser ang kanyang dashboard (Permit Verification tab) para i-check
     kung kumpleto at wasto ang mga in-upload na signed requirements bago ipadala sa Admin.
   - Kapag na-verify ni Adviser, ifo-forward ito sa Admin.

PHASE 4: FINAL ADMIN CLEARANCE
--------------------------------------------------------------------------------
4. Step 4: Final Admin Review (Uploaded Signed Documents)
   - Status: "Final Admin Review".
   - Lokasyon: Office of the Admin (Final Clearance).
   - Bubuksan ng Admin ang Admin Dashboard (Event Records / Approvals) para sa pinal na
     clearance ng in-upload na kompletong signed documents.

PHASE 5: PUBLICATION & LIVE EVENT
--------------------------------------------------------------------------------
5. Step 5: Approved (Published Event by Admin)
   - Iki-click ng Admin ang "Fully Approve & Publish".
   - Status: "Approved".
   - Lokasyon: Live in Portal (PUP Unisan Student Org Hub).
   - Ang event ay ganap nang naka-publish, makikita ng mga estudyante, at aktibo na ang attendance.

================================================================================
OPISYAL NA 5-STEP DOCUMENT TRACKING TIMELINE
================================================================================
1. Pending Adviser (Initial Review)
2. Adviser Approved (Printed & F2F Routing / Gathering Signatures) or Rejected (with reason)
3. Adviser Finalize Event Requirements
4. Final Admin Review (Uploaded Signed Documents)
5. Approved (Published Event by Admin)

================================================================================
STATUS AT LOCATION MAPPING SA SYSTEM
================================================================================
- Progress 1: Pending Adviser          -> Office of the Org Adviser (Initial Review)
- Progress 2: Adviser Approved         -> Student Organization Office (Gathering Signatures)
- Progress 3: Permit Verification      -> Office of the Org Adviser (Requirements Verification)
- Progress 4: Final Admin Review       -> Office of the Admin (Final Clearance)
- Progress 5: Approved                 -> Live in Portal (PUP Unisan Student Org Hub)
- Rejected (if any):                   -> Returned to Organizer (Correction Required) + Reason banner
================================================================================
